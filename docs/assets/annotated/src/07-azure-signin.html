AuthenticateOpens the browser sign-in for this cluster's tenant only.
Device codeShows a code to enter in the browser you choose, so you pick the account instead of reusing the browser's cached one.
Clear cached sign-inSigns out of this tenant's profile only, for when Authenticate keeps reusing the wrong account.
One profile per tenantEach tenant gets its own sign-in profile, so two clusters in two tenants never overwrite each other's login.
Staged connectSign in, check the subscription, open the tunnel, then SSH. A failure names the stage that failed.
